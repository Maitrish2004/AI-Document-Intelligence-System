AI Document Intelligence System

AI-powered full-stack application for PDF understanding, summarization, and question answering with accurate source highlighting.

 Key Features

-  PDF Upload & OCR Processing
-  AI-powered Document Summary
-  Ask AI questions about documents
-  Source Page Detection
-  Accurate Relevant Content Highlighting


Architecture

         React Frontend
              ↓
       Node.js + Express
              ↓
      OCR / PDF Processing
             ↓
      Gemini AI ─── MySQL
             ↓
      AI Answer + Source Page + Highlight
             ↓
      User Dashboard

Tech Stack

Frontend: React.js, JavaScript, HTML, CSS
Backend: Node.js, Express.js
Database: MySQL
AI: Google Gemini API
Processing: OCR, PDF Processing

Workflow



Upload PDF →  Process & Summarize  →  Ask AI
                    ↓
          AI Answer + Source Page
                    ↓
          Accurate Highlighting

 Objective

To help users quickly understand, search, and verify information from PDF documents using AI.
